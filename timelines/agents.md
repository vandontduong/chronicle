# Agents

<p class="meta">From tool calls to systems that do work</p>

## 2022–23 — Tool use and ReAct

Language models that call tools and interleave reasoning with acting. The unit stops being a single completion.

## 2023 — AutoGPT / early agent hype

Loops over an LLM with memory and tools. Fragile. Shows demand; does not yet show reliability.

## 2024–25 — Coding agents

Devin, Claude Code, Codex-class systems. The first agent product that people pay for because it finishes tasks.

## 2025–26 — Computer use

Models operate browsers and desktops. Capability is uneven; the research question is reliability under long horizons, not demos.
